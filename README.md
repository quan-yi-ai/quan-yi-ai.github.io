# AI Systems & Beyond

**AI Systems & Beyond** 是一个个人技术博客，记录人工智能、计算系统、软件工程及相关领域的学习、探索和实践。

- **博客地址**：https://quan-yi-ai.github.io/
- **博客框架**：VitePress
- **部署方式**：GitHub Pages
- **内容方向**：AI 与机器学习、系统与计算、工程实践、研究与笔记

## 本地预览

需要安装 Node.js 20 或更高版本。

```bash
npm install
npm run docs:dev
```

构建静态网站：

```bash
npm run docs:build
```

## 内容管理

公开文章位于 `docs/posts/`，网站配置位于 `docs/.vitepress/config.mts`。

本仓库为**公开仓库**，请勿提交飞书私有文档、未审核的文章内容或任何 API 凭证。飞书文档的目录整理及发布前审核在独立的私有仓库中进行，确认公开后再迁移到这里。
